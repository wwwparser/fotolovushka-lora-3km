Электроника и питание

Термин Значение в этом проекте
MCU, микроконтроллер Маленький компьютер на плате, выполняющий прошивку
Прошивка Программа, которую записывают в память ESP32
GPIO Программируемый сигнальный вывод контроллера
GND Общий провод, относительно которого измеряют напряжение
В / А / Вт Вольты — напряжение, амперы — ток, ватты — мощность
мА·ч Ёмкость батареи при её собственном напряжении
Вт·ч Энергия; удобнее для сравнения батарей с разным напряжением
18650 Формат цилиндрической ячейки; защита может увеличить длину
1S / 2S / 2P Одна ячейка последовательно / две последовательно / две параллельно; в MVP одна ячейка
DC/DC, boost Преобразователь постоянного напряжения; boost повышает его
MOSFET Транзистор, используемый здесь как электронный выключатель
High-side Ключ в плюсовом проводе питания
SOT-23 Очень маленький корпус детали с тремя выводами; нужен переходник для ручной сборки
Подтяжка Резистор, задающий известный уровень сигнала, когда его никто не переключает
Конденсатор Небольшой местный запас заряда, сглаживающий короткие провалы питания
PSRAM Дополнительная оперативная память для буферов изображения
Deep sleep Режим глубокого сна контроллера; вся отладочная плата может потреблять больше самого чипа

Камера и данные

Термин Значение
PIR Пассивный датчик изменения теплового излучения; не камера
NoIR Камера без блокировки ближнего инфракрасного света; совместимость шлейфа отдельно проверяется
ИК, 850 нм Подсветка невидимым/слабо видимым ближним ИК-светом; не то же излучение, которое воспринимает PIR
JPEG Сжатый файл фотографии; размер зависит от сцены и качества
160×120 19 200 пикселей; маленькая радиопревью-картинка, не снимок для распознавания лица
КиБ 1024 байта; 5 КиБ = 5120 байт
UART Последовательная передача по TX/RX
SPI Синхронная шина с тактом и выбором устройства
I²C Двухпроводная шина, здесь для часов
RTC / UTC Часы реального времени / единое время, не зависящее от часового пояса
SD / microSD Карта памяти двух размеров; электрические режимы и файловая система тоже важны
FAT32 Способ организации файлов на карте; два независимых владельца не должны менять его одновременно
USB host / device Ведущий / подключённое устройство; два USB-устройства обычным кабелем не образуют связь
MSC / PTP USB-доступ к накопителю / протокол получения фотографий; требуют разных драйверов

Радио

Термин Значение
LoRa Способ радиопередачи небольших объёмов данных
LoRaWAN Сетевой протокол поверх LoRa; этот MVP его не использует
868 МГц Частотный диапазон оборудования, не автоматическое разрешение любой передачи
SF Spreading factor: настройка с компромиссом между временем передачи и работой слабого канала
BW Ширина радиоканала; в расчёте 125 кГц
CR Кодирование для исправления части ошибок; в расчёте 4/5
ACK Подтверждение приёма фрагмента
CRC Контрольная сумма для обнаружения повреждения данных
Duty cycle Доля времени, занятого собственной передачей
RSSI / SNR Оценка уровня сигнала / отношения полезного сигнала к шуму
dBm Мощность относительно 1 мВт; 10 dBm = 10 мВт
dBi Усиление антенны относительно идеального изотропного источника
ЭИМ, EIRP Эквивалентная изотропно излучаемая мощность, учитывающая антенну и потери кабеля
SMA / RP-SMA Похожие разъёмы с разной комбинацией центральных контактов
Пигтейл Короткий коаксиальный кабель от платы к антенному разъёму
50 Ом Волновое сопротивление радиотракта

Корпус и печать

Термин Значение
CAD Проектирование точной трёхмерной геометрии
STEP Обменный формат CAD, удобный для дальнейшего редактирования
STL Поверхность из треугольников; используется слайсером, единицы в этом проекте — мм
Слайсер Программа, превращающая модель в движения конкретного принтера
G-code Команды принтеру; готовятся под его модель и материал, универсальный файл не выдаётся
FDM Послойная печать расплавленной пластиковой нитью
PETG / ASA / TPU Жёсткий пластик для прототипа / материал с устойчивостью к наружной среде / гибкий материал для пробной прокладки
Периметры Количество линий стенки при печати
Infill Заполнение внутреннего объёма; не заменяет толщину стенки
Brim Дополнительный край первого слоя против отрыва от стола
Допуск Разрешённое отклонение размера; для отверстий сначала печатают пробник
Термовставка Металлическая резьбовая втулка, устанавливаемая нагревом в пластик
IP Класс защиты проверенного изделия; закрытая STL-сетка не доказывает защиту от воды
