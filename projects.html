Проверено 07.10.2026. Ниже — первоисточники: репозитории авторов, их отчёты и официальные библиотеки. Чужие программы не запускались. Наличие кода не означает, что схема испытана на нашей радиотрассе или совместима с конкретной заводской камерой.

1. ESP32-CAM передаёт JPEG через LoRa

Atrop1n / LoRa_Camera_Trap — близкий к нашей исходной ветке проект: PIR, ESP32-CAM/OV2640, SX127x; приёмник хранит фото на SD и показывает через веб-сервер. Автор описывает длительные передачи и необходимость прямой видимости. Это сборка с собственной камерой, а не USB-доработка заводской ловушки. В README есть проблемное смешение обозначения SX1278 и частоты 868: выбранный модуль нужно проверять отдельно. Лицензия GitHub API не определена; код не перенесён в наш проект.

Xanuman / LoRa_ESP32-CAM_Trap — производная того же проекта. Полезна для сравнения изменений, но не считается независимым подтверждением работоспособности конструкции.

2. StuartCAM: передача изображения и файла

Отчёт автора StuartCAM и репозиторий Devices описывают Arducam OV2640, Arduino, SD и LoRa; отдельно рассматриваются ESP32-CAM и режимы SX127x/SX128x. Полезны алгоритмы передачи файлов и сравнение радиорежимов. Автор отдельно отмечает ограничения рабочего цикла. Быстрые примеры на 2,4 ГГц/FLRC нельзя переносить на наш 868-МГц LoRa/BW125; короткий тест передачи не подтверждает 3 км леса.

3. Передача JPEG между Raspberry Pi

LydiaDObeng / LoRa_Image — Python-проект: JPEG разбивается на пакеты SX127x и собирается на приёмнике. Хороший материал для лабораторного сравнения с нашей моделью фрагментов. Это не готовая автономная заводская ловушка. В описании используется 915 МГц, поэтому частоту и разрешённый режим нельзя копировать без проверки. Метрики PRR/BER и оценку SNR нужно перепроверить: они не заменяют измерения радио. Лицензия GPL-3.0.

4. Реальная переделка Bushnell: LoRa будит мост, фото идёт по Wi-Fi

Q42 / Hack The Poacher — авторский отчёт о модернизации Bushnell: добавлены плата LoRa и Wi-Fi SD-карта. LoRa сообщает о снимке, Raspberry Pi в ближайшем мосте просыпается и забирает фото по Wi-Fi, затем выполняет анализ и отправляет результат через Iridium. Это важный пример сохранения заводской оптики и PIR. Фото не передаётся через LoRa и USB-опрос здесь не используется.

Публикация Whytock и соавторов, 2023 описывает этот подход в полевой системе. Локальный Wi-Fi между камерой и мостом не решает напрямую нашу трассу 3 км; для такой архитектуры понадобятся близкий мост и другая схема питания.

5. AI-ловушка с LoRaWAN: передаются результаты распознавания

vondryas / ESP32-wild-animal-detector использует ESP32-S3, Edge Impulse/FOMO, PIR, SD и M5Stack LoRaWAN. README содержит неоднозначную фразу о передаче изображений. Проверенный sender.cpp отправляет 2–4 байта классов и количества обнаруженных животных, а не JPEG. Это вариант «тревога с результатом AI», полезный при малом эфирном бюджете. Требует LoRaWAN-сети и обученной модели; нашей прямой LoRa-базе напрямую не подходит. Лицензия BSD-3-Clause-Clear.

6. WildCAM: большой проект, требующий отдельного аудита

thewriterben / WildCAM_ESP32 объединяет ESP32-камеру, мониторинг животных и сетевые функции; README описывает LoRa/mesh и шлюз Raspberry Pi. Масштаб репозитория и список возможностей не подтверждают готовность всех подсистем. Рассматривать как материал для дальнейшего разбора; работающий USB-адаптер к нашим донорам и полевую надёжность по этой странице не устанавливаем. Лицензия MIT.

7. Официальная основа USB-хоста

Espressif / esp-usb, MSC Host — официальный драйвер накопителя для USB Host. Поддерживает BOT и Transparent SCSI. На его основе следует собирать отдельную прошивку S3. Это драйвер, а не готовая фотоловушка: он не управляет режимами камеры, не распознаёт новые снимки, не делает превью и не обеспечивает герметичность. API зависит от версии ESP-IDF; зафиксировать совместимую версию компонента и SDK перед реализацией.

8. Если камера использует PTP

gphoto / libgphoto2 и gphoto2 дают доступ к поддерживаемым цифровым камерам на Linux. Возможный путь для более мощной приставки Raspberry Pi при подтверждённом PTP. Это не библиотека для ESP32-S3 и не доказательство поддержки HC-300/Филин. Камеры MSC обычно обслуживает файловая система ОС; сначала определить USB-протокол своего устройства.

9. Что удалось найти для нашей идеи

Нашлись проекты передачи изображения через LoRa и документированные переделки заводских камер с LoRa-тревогой и Wi-Fi SD. Не найден подтверждённый универсальный проект «заводская камера из нашего каталога → периодический USB MSC → ESP32-S3 → JPEG по LoRa», который можно просто прошить и получить работающую систему. Это результат текущего поиска, а не утверждение, что такого проекта нигде нет.

В подборке есть готовые к изучению DIY-проекты, но серийную фотоловушку с доказанной передачей JPEG именно через LoRa на нашей частоте и с подходящим внешним интерфейсом не подтвердил. LTE, фирменный радиоканал, LoRaWAN-телеметрия и FLRC — разные технологии; похожее слово «дальнобойная» не делает камеру LoRa-фотоловушкой.

Практический выбор: USB-приставка для стенда с Boly BG410; сборка с нуля, если нужен полный контроль; б/у корпус Филина, если хочется сохранить заводскую оболочку. Для USB остаётся обязательным испытание автоматического возврата камеры в охрану.
