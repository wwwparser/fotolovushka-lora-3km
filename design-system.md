# Визуальное направление

Инженерный полевой справочник. Тёплый фон бумаги, тёмный лесной зелёный, тонкие линии, охристый акцент для ограничений. Заголовки Georgia, текст Segoe UI, числа/метки monospace. Асимметричный первый экран с иллюстрацией реального состава проекта. Навигация по главам, широкая смета, узкая колонка чтения. Без выдуманных характеристик и отзывов. Статус испытаний виден рядом с первой иллюстрацией.

Сетка до 1240 px, интервалы 8/16/24/32/48/64. На телефоне один столбец, меню раскрывается кнопкой, таблицы прокручиваются внутри своего контейнера. Все функции доступны клавиатурой, focus-visible, reduced-motion. Сайт статический и не отправляет введённые данные.
